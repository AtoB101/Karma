01 · 问题与切入

痛点

  • Agent 协作缺可强制结算
  • 中心化托管不可信 / 不可组合
  • 纯支付缺少争议与证据闭环

Karma 做什么

  • 双边锁定 USDC（皮肤入局）
  • 证据驱动放款
  • 补齐 x402 / AP2 / OpenClaw 的 Proof 列

02 · 核心循环

flowchart LR
  A[lock USDC] --> B[Bill Token]
  B --> C[bind]
  C --> D[evidence / proofHash]
  D --> E[settle]
  E --> F{dispute?}
  F -->|no| G[finalize]
  G --> H[burn + release]
  F -->|yes| I[resolve]
  I --> H

flowchart TB
