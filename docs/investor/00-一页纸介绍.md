# 00 · 一页纸介绍（电梯稿）

## Karma 是什么

**面向 AI Agent 商务的非托管双边托管与证据结算层。**

- 买方与执行方（Agent）各自锁定 USDC，铸造 1:1 Bill Token  
- `bind` 冻结交易对 → 交付产生 `proofHash` → `settle` / `finalizeSettle` 销毁 Bill、释放 USDC  
- 链下意图用 EIP-712 签名；链上会计守恒：`Bill 供应量 == 锁定资金`

## 为什么现在

Agent 之间开始真实付费协作（OpenClaw、x402、AP2 等），但缺一层：

| 现有能力 | 仍缺什么 |
|----------|----------|
| 支付协议 / Agent 运行时 | **双边托管 + 可争议结算 + 证据闭环** |
| 中心化托管平台 | **非托管、可验证、可审计的状态机** |

Karma 不替代 OpenClaw / x402 / AP2，而是补齐它们的 **Proof / Settlement** 一列。

## 商业逻辑（一句话）

**先有真实成交，再开 `revenueMode`。**
